# Uncertainty validation fixtures

Four sources for `ciw.uncertainty-validation.v1`, generated by `generate.py`
from one seeded standard-normal draw over a constant-velocity trajectory with
a shared scalar position innovation. The cases differ only in the covariance
they declare over identical errors:

| File | Declared covariance | Dependence | Expected |
| --- | --- | --- | --- |
| `consistent.json` | the true covariance | declared independent | consistent |
| `covariance-too-small.json` | one quarter of the truth | declared independent | NEES, NIS and coverage flag `covariance_too_small` and `under_covering` |
| `covariance-too-large.json` | four times the truth | declared independent | NEES and NIS flag `covariance_too_large`; coverage is uninformative at 64 samples |
| `unknown-dependence.json` | the true covariance | unknown | consistent numbers with `diagnostic_only` authority |

Register a file as a `uncertainty-validation` source and execute the operation
with its `source_id`; no repository binding is needed. Regenerate with:

```sh
python examples/uncertainty-validation/generate.py
```

The seed and sample count are fixed in the generator; no case was selected for
its outcome. The reference values are synthetic and are labelled as such in
every retained result. See [the operating guide](../../docs/UNCERTAINTY_VALIDATION.md).
